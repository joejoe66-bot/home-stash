# 🏠 Home Stash 屋企寶庫

Household stock, expiry reminders and shopping list — a PWA for the family.

- Front end: this repo, served by GitHub Pages → https://joejoe66-bot.github.io/home-stash/
- Data: Google Sheet + Apps Script API (protected by a family key)

Open the link on a phone or iPad and choose **Add to Home Screen**.
